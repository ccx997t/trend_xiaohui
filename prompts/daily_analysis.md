# 每日连板复盘

日期：`{DATE}`

读取：

- `config/analysis_rules.md`
- `baseline/current_baseline.md`
- 最近 3～5 个交易日的 daily 文件
- `data/structured/{YEAR}/{MONTH}/{DATE}.csv`
- 本次明确指定的新增 raw 文件（如有）

不要扫描全部历史 raw、读取全部 daily、重做全部统计或自动扩大范围。

任务：先建立可验证的板块梯队（题材、涨停/连板家数、最高板、候选的题材内位置与数据来源）；再找出全部二板，按“板块联动 → 个股地位 → 封板结构 → 换手成交”给出相对强弱。板块数据缺失时明确写“板块证据不足”，不得仅用成交额或涨幅给出高置信度排序；区分事实与假设，写入 `data/daily/{YEAR}/{MONTH}/{DATE}.md`。不直接修改长期规则。

强候选门槛：必须同时确认“整体板块联动”和“该二板为题材龙头或领涨核心”。逐只列出板块同步表现、同题材比较对象与龙头地位依据；一般前排、概念重合或单项成交额不能替代这两项证据。缺任一项，不列第一观察组；地位不明确时标记“龙头地位待验证”。这是用户指定的筛选方法，不作为已验证的市场规律。

最后报告本次读取和输出文件，以及最值得次日验证的 3～5 个观察点。
