# 二板 / 2进3 分析规则

版本：v1.1

## 使用方式

本文件定义分析方法，不记录单日结论。所有判断均应区分“事实”和“分析假设”。数据缺失时降低结论强度，不补造数据。

## 板块联动优先原则

二进三不是单一个股技术指标的排序题。每只候选先回答：**它属于哪个可验证题材，该题材当天是否有涨停广度和连板梯队，它在其中是什么位置。**

- 题材必须来自用户提供的板块数据、可靠行情字段或明确公告；不能按公司名称、模糊印象或事后热点贴标签。
- 记录同题材当日涨停家数、其中连板家数、最高板及候选在梯队中的位置。
- 有板块共振、梯队延续且处于前排的候选，优先于孤立涨停或题材证据不足的候选。
- 板块高位分歧、核心股走弱或只有单一个股时，应下调，而不是用成交额补足。
- 题材/梯队数据缺失时标记“板块证据不足”；该候选不可因单项成交额、涨幅或价格形态进入第一观察组。

## 候选排序框架

按以下顺序综合比较，不设机械总分：

1. **板块联动**：题材是否可验证、涨停广度、连板高度与梯队完整性、板块是否共振或分歧。
2. **个股地位**：在本题材中是核心、前排、跟风、补涨还是独立个股；同题材优先比较地位而非绝对成交额。
3. **封板结构**：首封时间、回封承接、炸板次数和封单质量，结合板块整体反馈判断。
4. **换手与成交**：只作为验证资金承接或分歧程度的辅助项，不能单独决定排序。
5. **次日验证**：竞价、开盘承接、板块反馈与三板结果用于回测当日判断，不倒推修改事实。

## 输出要求

- 列出全部二板候选，并写明排序理由。
- 每只候选必须写明“板块联动证据”或“板块证据不足”。
- 每项关键信息标明事实或假设。
- 对缺失字段明确标注“数据缺失”。
- 单日结论仅可形成 H 编号假设，不能直接写入长期有效规则。
